PROJETO: SISTEMA WEB DE CONTROLE FINANCEIRO PESSOAL
NOME PROVISÓRIO: MeuFinanceiro

==================================================
1. CONTEXTO E OBJETIVO DO PROJETO
==================================================

O projeto consiste no desenvolvimento de uma aplicação web de controle financeiro pessoal, com o objetivo de permitir que um usuário registre, organize e acompanhe suas movimentações financeiras.

O sistema deverá oferecer uma interface intuitiva e organizada, permitindo visualizar receitas, despesas, saldo disponível e resumos financeiros por período.

O projeto será desenvolvido como trabalho acadêmico da disciplina Laboratório de Programação, do curso de Ciência da Computação do Centro Universitário Unifacvest.

A Inteligência Artificial deverá ser utilizada como ferramenta ativa de apoio ao desenvolvimento, participando da criação da arquitetura, implementação, resolução de problemas e documentação.

3. REQUISITOS FUNCIONAIS DO SISTEMA
==================================================

IMPORTANTE:
Os requisitos desta seção representam a proposta inicial de funcionalidades do grupo. Eles não são exigências expressas do professor. Devem ser discutidos e refinados antes da implementação.

3.1. Dashboard financeiro

O sistema deverá possuir uma página inicial que apresente uma visão geral da situação financeira do usuário.

Deverá apresentar:
- Total de receitas do período selecionado.
- Total de despesas do período selecionado.
- Saldo resultante das receitas menos as despesas.
- Resumo das movimentações financeiras.
- Visualização gráfica da distribuição de despesas por categoria.
- Possibilidade de consultar diferentes períodos.

3.2. Gerenciamento de receitas

O usuário deverá conseguir:
- Cadastrar uma receita.
- Informar descrição, valor, data e categoria.
- Consultar receitas cadastradas.
- Editar receitas existentes.
- Excluir receitas.
- Visualizar o histórico de receitas.

3.3. Gerenciamento de despesas

O usuário deverá conseguir:
- Cadastrar uma despesa.
- Informar descrição, valor, data e categoria.
- Consultar despesas cadastradas.
- Editar despesas existentes.
- Excluir despesas.
- Visualizar o histórico de despesas.

3.4. Gerenciamento de categorias

O sistema deverá permitir organizar as movimentações financeiras por categorias.

O usuário deverá conseguir:
- Visualizar categorias disponíveis.
- Criar categorias personalizadas.
- Editar categorias.
- Excluir categorias, respeitando os vínculos com movimentações existentes.
- Diferenciar categorias de receitas e despesas.

Exemplos de categorias de despesas:
- Alimentação.
- Moradia.
- Transporte.
- Saúde.
- Lazer.
- Educação.
- Compras.
- Outros.

Exemplos de categorias de receitas:
- Salário.
- Rendimentos.
- Serviços.
- Outros.

3.5. Histórico e consulta de movimentações

O sistema deverá permitir:
- Visualizar todas as movimentações cadastradas.
- Identificar se cada movimentação é uma receita ou despesa.
- Consultar movimentações por período.
- Filtrar movimentações por categoria.
- Ordenar movimentações por data.
- Consultar os detalhes de uma movimentação.

3.6. Resumo e acompanhamento financeiro

O sistema deverá calcular automaticamente:
- Total de receitas.
- Total de despesas.
- Saldo do período.
- Evolução das movimentações ao longo do tempo.
- Distribuição das despesas por categoria.

Os valores apresentados deverão ser calculados a partir dos registros armazenados no banco de dados.

3.7. Persistência dos dados

- As movimentações e categorias deverão ser armazenadas no PostgreSQL.
- Os dados não poderão desaparecer ao atualizar ou fechar o navegador.
- As operações de cadastro, consulta, edição e exclusão deverão refletir corretamente no banco de dados.
