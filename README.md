# MeuFinanceiro - Sistema Web de Controle Financeiro Pessoal

Projeto acadêmico desenvolvido para a disciplina de **Laboratório de Programação** do curso de **Ciência da Computação** do **Centro Universitário Unifacvest**.

---

## 📌 Sobre o Projeto
O **MeuFinanceiro** é uma aplicação web intuitiva voltada para o gerenciamento de finanças pessoais. Permite o registro, categorização, filtragem e acompanhamento de receitas e despesas, fornecendo métricas de saldo e distribuição de gastos por meio de gráficos informativos.

---

## 🛠️ Stack Tecnológica

* **Backend:** Node.js (24.x), Express, Nodemon.
* **Frontend:** React (JavaScript moderno via Vite).
* **Banco de Dados:** PostgreSQL 16 provisionado via Docker e Docker Compose.
* **ORM:** Prisma ORM.
* **Gestão e Versionamento:** Git, GitHub (Semantic Commits) e Trello (Kanban).

## 📋 Metodologia e Organização

* **Quadro Kanban:** Gerenciamento visual do ciclo de desenvolvimento realizado via **Trello**.
* **Padrão de Commits:** Commits semânticos no formato `tipo: descrição breve` (ex: `feat:`, `fix:`, `docs:`, `chore:`).
* **Registro de Inteligência Artificial:** Documentação detalhada de prompts, análises críticas e decisões de engenharia registradas em [DOCUMENTACAO_IA.md](DOCUMENTACAO_IA.md).
